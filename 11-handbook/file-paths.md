# Important File Paths 📂

## Linux Paths 🐧

| Path | Meaning |
|---|---|
| `/etc/passwd` | Local user account list |
| `/etc/shadow` | Password hashes (root only) |
| `/var/log/auth.log` | Authentication logs |
| `/home/<user>/.ssh/` | SSH keys and config |
| `/tmp/` | Temporary files |

## Windows Paths 🪟

| Path | Meaning |
|---|---|
| `C:\Windows\System32\config\` | System config hives |
| `C:\Users\<user>\AppData\` | User app data |
| `C:\Windows\Temp\` | Temporary files |
| `C:\ProgramData\` | Shared app data |

## Quick Win 🎯
Visit these paths in a lab VM and note what files exist.
