# Packet Analysis with Wireshark 🦈

Packets are small network messages.

## Useful Filters

```bash
http  # Shows only HTTP packets.
dns  # Shows only DNS queries/responses.
ip.addr == 192.168.1.10  # Shows traffic to or from specific IP.
tcp.port == 443  # Shows traffic on TCP 443.
```

## Quick Win 🎯
Capture 60 seconds of your own browsing and filter for DNS.
