# OWASP Top 10 (Beginner Version) 🕸️

These are the most common web risks.

| Risk | Simple Meaning |
|---|---|
| Broken Access Control | Users can access things they should not |
| Cryptographic Failures | Weak encryption or plain-text secrets |
| Injection | App runs untrusted input as command/query |
| Insecure Design | Security not planned from start |
| Security Misconfiguration | Unsafe default settings |
| Vulnerable Components | Old libraries with known bugs |
| Auth Failures | Weak login/session controls |
| Data Integrity Failures | Updates/builds can be tampered |
| Logging Failures | Attacks are not detected |
| SSRF | Server fetches attacker-chosen URLs |

## Quick Win 🎯
Pick one risk and find one example in DVWA or PortSwigger labs.

## Memory Hack 🧠
Think: **A.C.I.D** = Access, Crypto, Injection, Design.
