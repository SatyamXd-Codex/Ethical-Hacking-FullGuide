# OSINT Basics 🔎

OSINT = Open Source Intelligence. You collect public information.

## Sources
- Search engines
- Public social profiles
- Domain records
- Device search engines

## Google Dork Examples

```bash
site:example.com filetype:pdf  # Finds PDF files on example.com.
intitle:"index of" "backup"  # Finds open directory listings with backups.
```

## Shodan Idea

```bash
shodan search apache country:"IN"  # Finds internet-facing Apache servers in India.
```

## Quick Win 🎯
Search your own website domain with `site:yourdomain.com` and list exposed files.

## Memory Hack 🧠
**P.U.B.L.I.C** = Public data only, Use ethically, Build notes, Link clues, Identify risk, Confirm facts.
