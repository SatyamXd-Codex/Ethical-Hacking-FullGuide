# Contributing Guide 🤝

Thanks for helping this beginner-friendly project! 🎉

## 1) Keep it Simple 🧒
- Use short sentences.
- Explain hard words in plain English.
- Add emojis where useful.

## 2) Keep it Safe 🛡️
- Only legal and ethical examples.
- Add a warning for risky commands.
- Never add content for illegal use.

## 3) Content Format 🧱
- Use headings and bullet points.
- Add at least one **Quick Win**.
- Add one **Memory Hack**.
- Every command must include an explanation.

Example:
```bash
nmap -sV 127.0.0.1  # -sV checks service versions on open ports.
```

## 4) Pull Request Steps 📦
1. Fork and create a branch.
2. Edit or add markdown files.
3. Check spelling and links.
4. Open a PR with clear summary.

## 5) Good First Contributions 🌱
- Fix typos
- Add analogies
- Add safer alternatives
- Improve tables
