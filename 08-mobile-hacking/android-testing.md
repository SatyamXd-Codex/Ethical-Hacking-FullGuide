# Android Testing Basics 📱

Use a test phone or emulator.

## ADB Commands

```bash
adb devices  # Lists connected Android devices/emulators.
adb shell  # Opens remote shell on device.
adb install app.apk  # Installs APK file to device.
adb logcat  # Streams Android system/app logs.
```

## Quick Win 🎯
Connect emulator and run `adb devices` + `adb logcat`.

## Memory Hack 🧠
**D.S.I.L** = Devices, Shell, Install, Logs.
