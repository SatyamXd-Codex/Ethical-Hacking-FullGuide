# Bug Bounty Getting Started 🐞

Bug bounty means you find valid security bugs and report responsibly.

## Platforms
- HackerOne
- Bugcrowd
- Intigriti

## Beginner Steps
1. Pick one program with clear scope.
2. Read policy and out-of-scope list.
3. Test one feature deeply.
4. Report with proof.

## Quick Win 🎯
Create platform accounts and bookmark 3 beginner-friendly programs.

## Memory Hack 🧠
**S.C.O.P.E** = Study rules, Check scope, Observe app, Prove bug, Explain impact.
